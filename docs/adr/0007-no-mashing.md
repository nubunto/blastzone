# No mashing, ever

No mechanic in the Engine reads how fast or how often a player presses buttons. Escaping a Grab, and anything else that other fighters resolve by mashing, is governed by Timers set in data. Mashing rewards physical endurance over decisions, is hard to reproduce for testing and replays, and hurts players' hands. Contributors coming from other platform fighters will expect mashing, so this ADR exists to stop it from being added back.
